# Tic-Tac-Toe

A classic 2-player Tic-Tac-Toe game on a 3x3 grid. 

This was one of my first coding projects from a couple years ago. a fun little experiment I built when I was just starting my coding journey. 🚀


## 🎮 How to Play
1. Clone the repository
2. Run main.py
3. Players take turns entering their moves
4. First to get 3 in a row wins!
